    On Image Generation

    Let's consider a regular 2D grid of dimensions \(H \times W\) as a base \(\Omega = \{ 1, \dots, H \} \times \{ 1, \dots, W \} \subset \mathbb{Z}^{2}\). Along with the RGB color space \(C = \mathbb{R}^{3}\), this grid forms a trivial bundle \(E = \Omega \times C\). An image is then a global section \(x : \Omega \to E\), such that \(x(u) = (u_{0}, u_{1}, I(u_{0}, u_{1}))\), where \(I\) is a function mapping each pixel coordinate to an RGB color vector. The space of all images \(\mathcal{X} = \Gamma(E)\) is the space of all possible such sections.
